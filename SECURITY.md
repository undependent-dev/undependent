# Security Policy

## Reporting a Vulnerability

We take security seriously. If you discover a vulnerability in Undependent:

1. Email: security@undependent.dev
2. We respond within 24 hours
3. We credit responsible disclosures
4. We do not prosecute reporters

## Supported Versions

| Version | Supported |
|---------|-----------|
| 1.0.x   | ✅ Yes    |

## Security Features

- Lockfile integrity verification (SHA256 hashes)
- CVE scanning via OSV API
- Attack surface mapping
- License compliance checking
